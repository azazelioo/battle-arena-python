# Сценарий демонстрации на 7–10 минут

1. Запустите GUI, выберите два локальных игрока: воин и маг без экипировки. Покажите предпросмотр характеристик.
2. Проведите контрольную последовательность: огненный шар, защита, атака, тяжёлый удар, лечение, атака. Укажите HP 103/80 и энергию 28/32.
3. Объясните путь кнопки через GameController → BattleEngine.submit → Action.execute → Character → BattleSnapshot.
4. Покажите недоступное лечение при полном HP и почему отказ не меняет ход.
5. Начните бой следопыта и мага. Примените отравленную стрелу. У мага 71 HP. Сохраните и загрузите: остаётся 71, а не 64. Примените противоядие.
6. Завершите бой сдачей. Покажите статистику и одну запись в истории. Повторная загрузка законченного боя не создаёт дубликат.
7. Запустите `python -m arena --cli` и покажите те же действия через текстовый интерфейс.
8. Запустите `python -m pytest`, `python -m mypy arena`, `python tools/count_lines.py`, `python tools/benchmark.py`. Используйте фактические результаты своего компьютера.

## Файлы для объяснения

- model.py: Stats, StatBonus, History[T], снимки.
- character.py: ограничение HP и энергии, независимость инвентарей.
- actions.py: контракт Action и разные execute/preview.
- effects.py: одинаковый hook с разными эффектами.
- battle.py: транзакционная граница ожидаемых команд и порядок хода.
- bot.py: стратегии по неизменяемым входам.
- storage.py / validation.py: проверка JSON и атомарная запись.
- controller.py: пауза, замена матча только после полной загрузки.

## Вопросы для подготовки

Почему архетипы — данные, а не три одинаковых подкласса? Чем фактический урон отличается от расчётного? Почему preview не расходует защиту? Почему load не вызывает начало хода? Что будет при двойном нажатии или старом callback? Зачем историю ограничивать и проверять match_id?

Проверьте с преподавателем допустимость Python вместо C++, использование инструментов генерации кода, требуемый метод подсчёта строк, трактовку 400–600 строк ООП и обязательность 100% покрытия. Эти решения нельзя принять от имени преподавателя.

## Дополнительные проверки завершённой версии

Покажите фильтр истории и переходы по записанным ходам. Измените размер шрифта до 20 и прокрутите экран. Затем выполните:

```bash
python -m pytest --cov=arena --cov-report=json:coverage.json
python tools/check_acceptance.py --coverage coverage.json
python -m black --check arena tests tools
python tools/benchmark_gui.py --cycles 100
```

Сверьте результаты с ACCEPTANCE.md; организационные пункты 15–16 подтверждаются отдельно.
