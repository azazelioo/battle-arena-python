# Результаты проверки

Дата: 16 сентября 2026. Проверялась именно реализация этого репозитория.

## Автоматические проверки

- Python 3.12.14 с Tcl/Tk 9.0: **255 тестов прошли**, включая 13 проверок настоящих окон.
- Python 3.14.6 без Tcl/Tk: **242 теста прошли**, модуль GUI-тестов пропущен по отсутствию `_tkinter`.
- mypy 1.18.2, strict: **20 модулей без ошибок**.
- Покрытие строк: **1544/1583 (97.54%)**.
- Покрытие ветвей: **318/340 (93.53%)**.
- Совместный показатель coverage: **96.83%**.

У домена, действий, эффектов, стратегий, контроллера и сериализации покрыты все исполняемые строки. Ни один игровой модуль не исключён из отчёта. Стандартные исключения coverage: две строки TYPE_CHECKING-импорта в effects.py и шесть строк деклараций overload в model.py; это только статическая типизация, не исполняемая логика игры. Непокрытые строки относятся преимущественно к запуску и отдельным обработчикам GUI. Полные агрегаты по модулям: [coverage-summary.json](coverage-summary.json).

Локальный Python 3.12 использовал чистый Python-трассировщик coverage, так как доступный бинарный C-трассировщик собран для Python 3.14. Coverage сообщил предупреждение и выполнил измерение без C-ускорения. В обычном окружении после установки зависимостей используется подходящая сборка для текущего Python.

## Проверенные сценарии

Контрольные числа из ТЗ; минимум физического урона; магия сквозь броню; частичное лечение; яд, защита и противоядие; добивание, сдача и сотое действие; неверные и повторные команды; инициативы; обе стратегии во всех парах архетипов; независимые снимки; повреждённые сохранения; повторная загрузка яда; сбой записи без потери слота; история из 50 длинных матчей; реальные кнопки настройки, сохранения, загрузки и истории; отмена callback; консольные сессии.

Скриншот README снят с настоящего Tkinter-окна после четырёх ходов контрольного примера.

## Производительность

1000 независимых команд, включая обычную атаку, яд и ожидаемый отказ. Измеряются submit и подготовка снимка без ожидания игрока/бота.

- Медиана: 0.0197 мс.
- p95: 0.0328 мс.
- Максимум: 0.2229 мс — ниже 500 мс на этой машине.
- Python: 3.14.6; платформа: macOS-26.4-arm64-arm-64bit-Mach-O.
- Диапазон событий: [1, 6].
- Память после 100 матчей с сохранением 50: 340818 байт; пик 369591 байт.

[Машиночитаемый отчёт](benchmark.json). `tracemalloc` измеряет только Python-выделения. Модель CPU не определялась; указанная архитектура — arm. На компьютере защиты измерения необходимо повторить и записать модель процессора. Графические ресурсы и вся память процесса этим бенчмарком не измеряются.

## Границы проверки

GUI проверялся на macOS. Workflow для Python 3.12–3.14 и Xvfb на Ubuntu добавлен; результат удалённого CI следует смотреть в GitHub Actions. Windows в этой сессии не проверялся. Наличие Tcl/Tk, читаемость на экране защиты и завершение приложения необходимо проверить на целевом компьютере.
